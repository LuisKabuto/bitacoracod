# Proyecto

Bitácora Cloud PRO

# Objetivo

Desarrollar un sistema profesional para la gestión operativa de oficinas.

El proyecto evolucionará por Sprints.

Nunca deben romperse funcionalidades existentes.

# Reglas

- No modificar Firebase sin autorización.
- No modificar Firestore sin autorización.
- No eliminar funcionalidades existentes.
- Mantener compatibilidad con versiones anteriores.
- Hacer cambios pequeños.
- Un objetivo por commit.
- Explicar siempre qué archivos fueron modificados.
- Evitar código duplicado.
- Mantener nombres claros.
- Documentar funciones complejas.

# Estilo

- Código limpio.
- JavaScript moderno.
- HTML semántico.
- CSS organizado.
- Comentarios solo cuando aporten valor.

# Flujo de trabajo

Analizar

Diseñar

Implementar

Probar

Commit

Push

# Filosofía

La aplicación debe parecer un software empresarial moderno.

Cada mejora debe aumentar:

- claridad
- velocidad
- mantenibilidad
- experiencia del usuario
